# Handoff 생성 

## 1. 사실 수집 (추측 금지)
- git status, git log --oneline -10 실행 
- pnpm check 실행
- 확인하지 못한 것은 "미검증"으로 표시 

## 2. docs/HANDOFF.md 덮어쓰기 (아래 섹션 고정)
- 최종 갱신 일지 
- 현재 단계와 목표 
- 완료한 것 : 항목마다 커밋 해시 또는 검증 결과 첨부 
- 진행 중인 것 
- 다음 할 일: 새 세션이 바로 실행할 수 있게 구체적으로, 순서대로 
- 알려진 문제와 리스크 
- 이번 세션의 결정: DECISIONS.md 항목 번호만 (내용 반복 금지)

## 3. 자기 검증 
- 문서에 적은 파일, 함수가 실제로 존재하는지 확인
- 150줄 이내 유지, 작업 로그를 통쨰로 넣지 말고 필요한 것만 

## 4. 커밋 
- docs: handoff 갱신 (<현재 단계>)

## 이어받기 (새 세션)
1. AGENTS.md -> docs/HANDOFF.md 순서로 읽기
2. git log, pnpm check로 문서 내용이 실제와 맞는지 확인
3. 다르면 작업 전에 먼저 보고 
4. "다음 할 일" 1번부터 시작
